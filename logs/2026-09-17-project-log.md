# GS-NAV-Module 项目工作日志

**日期：** 2026-09-17  
**当日概况：** 完成导航应用主体落地、导航界面升级、传感器驱动接入、驱动管理与数据监看页面开发、DLIO 激光惯性里程计接入及 ROS 话题配置修复。当天共形成 10 次提交，当前版本相关自动化测试全部通过。

## 1. 导航应用主体落地

1. 新增 `gs_nav_demo` 导航应用，建立 ROS 2 Python 包、启动文件、参数配置、地图处理、导航计算、相机渲染和 Qt 导航界面等基础模块。
2. 实现多途径点选择与 `NavigateThroughPoses` 导航、栅格地图/点云地图显示、全局路径叠加、相机画面导航提示等核心功能。
3. 增加 PCD/PLY 点云读取、Nav2 栅格地图导入导出、点云转栅格、地图画笔编辑与撤销等本地地图处理能力。
4. 配套加入地图处理、导航界面和渲染相关测试，为后续调整建立回归验证基础。

## 2. 导航界面与交互升级

1. 重构导航设置页布局，以地图为主要操作区、相机为辅助预览区，并将导航选点与地图编辑拆分为独立工作区。
2. 优化途径点管理，支持指定途径点重选、单点删除和自动重新编号；开始导航后切换到专用实时导航页面。
3. 增强三维点云交互，支持旋转、平移、缩放、重置视角，并叠加途径点、全局路径和机器人朝向。
4. 完善导航结束流程：到达终点后显示完成提示并自动返回地图页，同时允许用户立即返回。
5. 将默认点云地图随包安装，并支持通过启动参数替换地图或关闭自动加载。

## 3. 项目结构与安全清理

1. 将应用包由 `gs_nav_demo` 统一更名为 `gs_nav_app`，同步更新包名、模块名、资源索引、启动文件、测试引用和安装配置。
2. 清理仓库内不应继续保留的账号说明、服务器连接配置及密钥文件，降低敏感信息留存风险。
3. 补充根目录 `build.sh`，构建前清理当前工作空间残留的环境路径，再基于 ROS 2 Humble 执行 `colcon build --symlink-install`，并允许覆盖工作空间内的 RealSense 包。

## 4. 传感器驱动接入

1. 引入并适配 Livox ROS 2 驱动，围绕 MID360 调整配置、启动入口、发布逻辑和驱动源码结构。
2. 新增 RealSense ROS 2 驱动组件，包括 `realsense2_camera`、消息接口和设备描述包，并提供 D435i 启动入口。
3. 在 `gs_nav_app` 中补充 Livox 与 RealSense 的运行依赖，使导航应用可直接管理本地传感器驱动。
4. 将默认相机图像及内参话题切换到 D435i 的命名空间：`/camera/camera/color/image_raw` 与 `/camera/camera/color/camera_info`。

## 5. 传感器管理功能

1. 在 Qt 应用中新增独立“传感器管理”页面，分别提供雷达和相机的启动参数配置、启动与停止控制。
2. 支持启动 Livox MID360 和 RealSense D435i，可配置雷达输出、发布频率、坐标系、JSON 配置路径，以及相机命名空间、序列号、RGB/深度/IMU、同步、对齐和点云等选项。
3. 新增“全部 / 雷达 / 相机”实时日志视图，统一展示启动命令、驱动输出、错误信息和进程退出码。
4. 使用独立进程组管理 `ros2 launch` 及其子进程；停止驱动或关闭软件时按 SIGINT、SIGTERM、SIGKILL 逐级清理，避免残留节点和话题。

## 6. 传感器数据实时监看

1. 新增独立“传感器数据”页面，可从传感器管理页进入，集中查看雷达点云、相机视频和 IMU 数据。
2. 根据 ROS 2 消息类型自动发现兼容话题，同时支持手动输入完整话题名称；兼容 `PointCloud2`、Livox `CustomMsg`、`Image` 和 `Imu`。
3. 雷达页支持点云三维旋转、平移和缩放；相机页显示实时原始视频帧；IMU 页展示坐标系、时间戳、姿态四元数、角速度、线加速度及协方差。
4. 监看功能采用临时动态订阅，切换话题时替换旧订阅，离开页面时统一释放，不影响已启动的传感器驱动。
5. 新增话题类型筛选、Livox 自定义消息转换及三类传感器实时渲染测试。

## 7. DLIO 激光惯性里程计接入

1. 在 `src/gs_nav_slam` 下新增 ROS 2 包 `direct_lidar_inertial_odometry`，引入 DLIO 里程计、建图节点及 NanoGICP 配准实现。
2. 支持连续时间运动校正、点云去畸变与体素化、IMU 标定、关键帧地图构建，并提供 `SavePCD` 服务保存生成的点云地图。
3. 新增统一启动文件，可配置点云话题、IMU 话题、仿真时钟和 RViz；默认对接 Livox MID360 的 `/livox/lidar/pointcloud` 与 `/livox/imu`。
4. 配置中使用单位外参，避免重复应用已由 Livox 驱动处理的 MID360 安装旋转和平移；同时补充 MID360 启动方法及数据要求说明。

## 8. ROS 配置问题修复

1. 修复参数文件中的节点名不匹配问题，将配置作用域由 `gs_ar_nav` 调整为实际运行节点 `/gs_qt_nav`，确保参数能够被正确加载。
2. 将相机、相机内参、地图和路径话题保存为节点运行属性，订阅、启动日志及界面等待提示均使用真实配置值。
3. 增加配置与运行节点名一致性测试，并验证导航设置页、实时导航页能够同步显示当前相机话题。
